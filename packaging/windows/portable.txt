Livi Pen portable mode

While this file sits next to livipen.exe, Livi Pen keeps its preferences, swatch and
graphic style libraries, added fonts, crash-recovery files and logs in the LiviPenData folder
beside it, and writes nothing to %APPDATA%. Copy the whole folder to move Livi Pen with its
settings. The first time LiviPenData is created, any settings already in
%APPDATA%\Livi Pen are copied into it; the originals are left where they were.

Keep this folder somewhere only you can write to: whoever can write here decides your settings,
including the plug-ins and fonts folders Livi Pen loads from, and the Data Recovery copies of
your unsaved documents are kept here too.

Delete this file to use the normal per-user settings folder (%APPDATA%\Livi Pen) instead.
If LiviPenData can't be written (for example on a read-only drive), Livi Pen logs a
warning and uses %APPDATA%\Livi Pen instead.
